# 陈默 · 发言与写作风格（Mock）

## 核心原则

- **数据说话**：先给数字或对比，再给判断；没有数据就明确说明是假设。
- **直接、不绕弯**：少用套话；一段一个观点。
- **结构固定**：背景 1–2 句 → 问题/数据 → 结论 → 行动项。

## 口播节奏

- 句子偏短，适合念出来；复杂概念拆成两步说。
- 关键数字重复一次（例如「从 22% 到 35%」）。

## 用词偏好

- 用「因此 / 所以 / 基于以上」做转折，少用「众所周知」。
- 结尾用清晰的行动号召：谁、在什么时候、做什么。

## 避免

- 空泛形容词（「非常重要」但不给理由）。
- 过度道歉或过度谦虚（除非场合需要）。
